# 蓝天大地配色调整计划（adhd-demo）

## Summary
- 将页面整体背景改为“顶部浅天蓝 → 过渡到近白蓝/奶油白 → 底部带一点暖米的地面感”的纵向渐变。
- 将主要 UI 表面（卡片、输入框、列表步骤等）从偏冷白/偏粉玻璃感，调整为淡粉/奶油/燕麦系，更接近“蓝天大地”氛围。
- 将强调色（按钮、聚焦描边/阴影、进度条末端色）从偏粉改为暖沙色，以保持整体统一。

## Current State Analysis
- 主题变量集中在 [styles.css:root](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L1-L15)，当前 `--bg` 为粉白系，`--accent` 指向 `--pink`。
- 全屏背景在 [styles.css body::before](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L41-L51)，线性渐变为粉白到粉紫，叠加粉/蓝/绿三组径向光斑。
- 卡片/输入框等表面普遍使用白色半透明背景（例如 [.card](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L68-L78)、[.input](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L182-L187)、[.field-input/.field-select](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L252-L268)、[.field-textarea](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L270-L286)、[.list](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L423-L429)、[.step](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L439-L456)）。
- 聚焦阴影与按钮投影存在硬编码粉色 `rgba(255, 79, 179, …)`（见 [styles.css 中的匹配处](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L47-L51) 等），需要统一替换为“暖沙色强调”。

## Proposed Changes

### 1) 引入“蓝天大地”配色变量（styles.css）
目标：将用户给定的色板落到 CSS 变量，后续所有背景/表面/强调都由变量驱动，便于微调。

修改文件：
- [styles.css](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css)

具体调整：
- 在 `:root` 内新增/调整变量（保留现有 `--text/--muted/--radius/--shadow` 等不动，避免影响排版与可读性）：
  - 背景渐变锚点
    - `--sky-100: #DFF3FF;`（顶部浅天蓝）
    - `--sky-50: #F7FBFF;`（近白蓝过渡）
    - `--cream-50: #FFF8F2;`（奶油白）
    - `--ground-50: #F3E7DA;`（暖米色，用于底部“地面”轻微暖感）
  - UI 表面（卡片/输入框等）
    - `--oat-50: #F5EBDD;`（浅燕麦）
    - `--sand-50: #EEDFCC;`（浅沙色）
    - `--milk-tea-50: #E8D8C8;`（奶茶米棕，用作强调色）
  - 全局背景与强调
    - `--bg: var(--cream-50);`（html fallback 背景）
    - `--accent: var(--milk-tea-50);`（由用户选择“改为暖沙色”）
- 将 `--pink` 保留为备用点缀色，但不再作为主强调色来源（避免大面积粉色抢戏）。

### 2) 替换全屏背景渐变为“天空 → 奶油地面”（styles.css body::before）
目标：实现用户描述的视觉：顶部浅天蓝，向下过渡到白/奶油白，主体保留淡粉/奶油感，并带一点“地面”暖色收尾。

修改文件：
- [styles.css body::before](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L41-L51)

具体调整：
- 将当前 `linear-gradient(180deg, #fff7fb …)` 替换为：
  - `linear-gradient(180deg, var(--sky-100) 0%, var(--sky-50) 34%, var(--cream-50) 72%, var(--ground-50) 100%)`
  - 说明：底部仍以奶油白为主（72% 开始），只在最底部引入少量暖米，符合用户选择“更奶油白”。
- 将粉色径向光斑替换为更贴合主题的光斑：
  - 顶部以 `--sky-100/--sky` 为主（更像天空散射）
  - 底部以 `--oat-50/--sand-50` 为主（更像地面反射）
- 光斑实现使用 `color-mix(in srgb, <color> <pct>, transparent)` 生成半透明色（项目已在输入框聚焦处使用 `color-mix`，兼容性策略保持一致）。

### 3) 卡片与装饰层改为奶油/燕麦系（styles.css .card / .card::before / .card::after）
目标：页面主体保留淡粉/奶油感，但不再显得“冷白玻璃”，同时保持现有的层次与质感。

修改文件：
- [.card](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L68-L78)
- [.card::before](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L80-L90)
- [.card::after](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L92-L101)

具体调整：
- `.card` 的背景渐变从纯白半透明调整为：
  - 上部更奶油（`--cream-50`）
  - 下部更燕麦/暖米（`--oat-50` 或 `--ground-50`）
- `.card::before` 中的粉色装饰光斑替换为 `--sand-50/--milk-tea-50`，保留少量 `--sky` 作为“天空反光”。
- `.card::after` 的点阵层保持，但可轻微降低对比（将点阵颜色从 `rgba(31, 36, 48, 0.07)` 调浅一点），避免在更浅背景上显脏。

### 4) 输入框/设置面板/列表步骤等表面色统一（styles.css）
目标：将用户点名的“输入框/卡片”统一为暖奶油/燕麦系；同时把同风格的列表块、步骤项等一起改，以免出现一部分偏白一部分偏奶油的割裂。

修改文件（同一文件内多处）：
- [.input](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L182-L187)
- [.field-input/.field-select](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L252-L268)
- [.field-textarea](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L270-L286)
- [.settings / .settings[open]](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L295-L318)
- [.bubble](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L386-L394)
- [.list](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L423-L429)
- [.step / .step.is-child](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L439-L456)
- [.step-text:focus](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L522-L525)

具体调整：
- 以上区域的 `background: rgba(255,255,255, …)` 改为基于 `--cream-50/--oat-50/--sand-50` 的半透明混合（仍保持轻微“玻璃感”，但色相偏暖）。
- 聚焦态（`box-shadow`、`border-color`）去掉硬编码粉色：
  - `border-color` 继续使用 `color-mix(... var(--accent) ...)`
  - `box-shadow` 使用 `color-mix(in srgb, var(--accent) 20%, transparent)` 一类方案生成暖沙色光晕

### 5) 强调色迁移：按钮/Logo/进度条末端色（styles.css）
目标：落实用户选择“强调色改为暖沙色”，并避免界面存在明显粉色元素破坏统一感。

修改文件：
- Logo 渐变：[.logo](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L122-L133)
- 主按钮：[.btn-primary](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L351-L356)
- 进度条：[.meter-bar](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L404-L410)、[.step-progress-fill](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L567-L573)
- 其他粉色硬编码：`rgba(255, 79, 179, …)` 出现点（例如 [styles.css:L481](file:///d:/Github_Try/xiaohan/adhd-demo/styles.css#L479-L483)）

具体调整：
- `.logo` 与 `.btn-primary` 的渐变从 `(--pink → --sky)` 改为 `(--accent/--milk-tea-50 → --sky)` 或 `(--sand-50 → --accent)`（以最终视觉效果为准）。
- `.btn-primary` 的投影颜色从粉色投影改为暖沙色投影（与按钮本身一致）。
- 进度条渐变末端从 `--pink` 替换为 `--accent`，形成“绿 → 天空蓝 → 暖沙”的自然过渡。

## Assumptions & Decisions
- 强调色：按用户选择改为暖沙色（以 `#E8D8C8` 为核心），粉色只作为备用点缀变量保留，但不再参与主 UI 渐变。
- 底部地面：按用户选择“更奶油白”，因此底部暖米（`#F3E7DA`）只占渐变末端小比例，用作“轻微地面感”，不做明显深色地面。
- 不改动 HTML 结构与 JS 行为，仅通过 CSS 配色/变量调整达成效果。
